## Important note

- DOSBox boots by default to DOS shell
- To autostart directly an app from be it directory or archive there must be a present DOSBOX.BAT file inside your app's top directory (use [dosbox_setup.sh](https://github.com/Apaczer/miyoo_tools/raw/4d64b85bface3a633a300040afc86eaf7061dea3/dos/dosbox_setup.sh.ipk) utility to generate one)
- For smooth playback set the framerate and appropriate cycles value by trial-and-error (to see changes activate on-scren-display notifications)
- more info on emulator's manual and README in target installation directory

*) _You can find legacy setup for old DOSBox binary in [this thread](https://github.com/TriForceX/MiyooCFW/discussions/268)._
